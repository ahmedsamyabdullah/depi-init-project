# Team Project Init

This folder is run **by the team leader only**. It creates the shared Terraform state bucket and the IAM users for the team.

| | Student | Leader |
|---|---|---|
| Write code | ✅ | ✅ |
| `terraform plan` | ✅ | ✅ |
| `terraform apply` | ❌ | ✅ |

---

## Leader Steps

### 1. Prepare

1. Use an IAM admin user with MFA. Do **not** use the root user.
2. In all `.tf` files, replace `depi-team-n` with your project name.
3. In `team.tf`, replace the 4 student names in `aws_iam_user`.

### 2. Create the bucket and the users

```
terraform init
terraform apply
```

> If the bucket name is already taken, change it in `bucket.tf` and apply again.

### 3. Move this folder's state to the bucket

1. Create `backend.tf` in this folder:
   ```hcl
   terraform {
     backend "s3" {
       bucket       = "depi-team-n-tfstate"
       key          = "init/terraform.tfstate"
       region       = "us-east-1"
       encrypt      = true
       use_lockfile = true
     }
   }
   ```
2. Run:
   ```
   terraform init -migrate-state
   Remove-Item terraform.tfstate, terraform.tfstate.backup
   ```

### 4. Give each student console access

For each of the 4 students:

1. Go to **IAM → Users → the student → Security credentials**.
2. Click **Enable console access**.
3. Choose **Autogenerated password** and check **User must create a new password at next sign-in**.
4. Copy the sign-in URL and password.

### 5. Create the project repo

1. Create a new GitHub repo for the project.
2. Add `backend.tf`:
   ```hcl
   terraform {
     required_version = ">= 1.10"

     backend "s3" {
       bucket       = "depi-team-n-tfstate"
       key          = "project/terraform.tfstate"
       region       = "us-east-1"
       profile      = "depi-team-n"
       encrypt      = true
       use_lockfile = true
     }

     required_providers {
       aws = {
         source  = "hashicorp/aws"
         version = "~> 6.0"
       }
     }
   }

   provider "aws" {
     region  = "us-east-1"
     profile = "depi-team-n"

     default_tags {
       tags = {
         Project   = "depi-team-n"
         ManagedBy = "terraform"
       }
     }
   }
   ```
3. Copy `.gitignore` into the project repo.
4. Push to `main`.
5. Add the students as collaborators.
6. Protect `main`: require a pull request with 1 approval.
7. Add your admin keys to the shared profile name:
   ```
   aws configure --profile depi-team-n
   ```

### 6. Send each student (private message)

- Sign-in URL
- Username
- Password
- Project repo URL

### 7. Daily work: apply after each merge

1. Review the PR.
2. Merge it.
3. Run:
   ```
   git pull
   terraform plan
   terraform apply
   ```

> If `plan` shows an unexpected **destroy** or **replace**, stop and do not apply.

---

## Student Steps

### 1. Sign in

1. Open the sign-in URL from the leader.
2. Sign in with your username and password.
3. Set a new password.

### 2. Create an access key

1. Go to **IAM → Users → your user → Security credentials**.
2. Click **Create access key** and choose **CLI**.
3. Run (use this exact profile name, it is written in `backend.tf`):
   ```
   aws configure --profile depi-team-n
   ```

> Never push your access key to Git or share it with anyone.

### 3. Clone the project

```
git clone <project-repo-url>
cd <project-repo>
terraform init
```

### 4. Daily work

1. Get the latest code:
   ```
   git checkout main
   git pull
   git checkout -b <your-branch>
   ```
2. Write your code in your own file (`network.tf`, `compute.tf`, `data.tf`, or `security.tf`).
3. Run:
   ```
   terraform fmt
   terraform validate
   terraform plan
   ```
4. Push your branch and open a PR.
5. Paste the `plan` output in the PR description.
6. Wait for the leader to merge and apply.

---

## Rules

- Never run `terraform apply`. Only the leader does.
- Never put passwords or secrets in the code.
- If `plan` says **state lock**, wait a minute and try again.
- If `plan` says **AccessDenied**, tell the leader.
